# Island State — Caribbean Life Sim Concept

A concept website and early design outline for a Caribbean-first open-world life simulation.

This is not a playable 3D game. The island illustration is made with CSS shapes. Jobs, vehicles, property systems, multiplayer, and a large open world are proposed ideas, not implemented features.

## Run locally
Open `index.html` in a modern browser.

## Files
- `index.html`: concept page.
- `style.css`: responsive styling.
- `app.js`: navigation behavior.
- `docs/game-design-outline.md`: early design outline.
